Tag <a> (âncora / link)

A tag <a> define um hiperlink. O atributo href (hypertext reference) é obrigatório e especifica o destino do link.

1. Link para site externo

Abre o site no mesmo navegador (substitui a página atual).

Visite o Google

2. Link para site externo em nova aba

O atributo target="_blank" abre o link em uma nova aba ou janela.

Visite W3Schools (nova aba)

3. Link para outra seção da mesma página

Usa o caractere # seguido do id de um elemento para navegar até ele.

Ir para a seção final

4. Link para enviar e-mail

Usa o prefixo mailto: para abrir o programa de e-mail padrão.

Enviar e-mail para contato@exemplo.com

5. Link para realizar chamada telefônica

Usa o prefixo tel: para discar um número em dispositivos móveis.

Ligar para (11) 99999-9999

Seção final (destino do link interno)

Você chegou aqui clicando no link com href="#secao-final".

Voltar ao topo (uso de # sozinho recarrega a página no topo).

Nota prática: O atributo href é obrigatório. Links sem href não são interativos. Use target="_blank" com cuidado para não sobrecarregar o usuário com muitas abas. O link # (sem destino) recarrega a página ou navega para o topo.
