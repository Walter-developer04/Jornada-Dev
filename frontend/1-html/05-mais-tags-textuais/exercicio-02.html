Para que serve a tag pre ?

Usada para exibir código-fonte, poemas ou textos com formatação de espaços. Preserva quebras e espaços.
EX: 

        function ola() {
            console.log("Olá, mundo!");
        }

Se eu colocasse esse mesmo código dentro de um <p>, ele ficaria todo em uma linha só.

A tag <mark> (Marca-texto)

A tag <mark> destaca visualmente um trecho do texto com fundo amarelo, similar a um marca-texto em papel.

Este é um texto normal. Esta parte está destacada e chama a atenção do leitor.

Outro exemplo: a palavra HTML foi marcada para ênfase visual.
