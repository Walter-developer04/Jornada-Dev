Como deixar o texto em negrito

Para deixar uma parte do texto em negrito se usar a tag <b> ou a tag <strong>.
A tag <strong> é semanticamente mais recomendada para acessibilidade e SEO, sendo a mais usada em textos profissionais.
A tag <b> é apenas visual considerada uma tag que não tem tanto valor semantico.

Como deixar o texto em itálico

Para deixar uma palavra em itálico se usar a tag <i> ou <em> EX: Esse texto está em itálico usando a tag i.
Nesse segundo exemplo está sendo usado a tag <em> para deixar em itálico.
A tag <em> indica ênfase semântica (recomendada).
A tag <i> é apenas visual e menos utilizada em conteúdos principais.
