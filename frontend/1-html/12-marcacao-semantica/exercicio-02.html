Tags de citação

Tag <abbr>

Marca uma abreviação. O atributo title mostra o significado completo ao passar o mouse.

Estou aprendendo HTML no curso.

Tag <cite>

Marca o título de uma obra, como um livro ou um filme.

Meu livro favorito é O Pequeno Príncipe.

Tag <dfn>

Marca um termo que está sendo definido na frase.

Um navegador é o programa usado para abrir páginas da web.

Tag <address>

Marca informações de contato de uma pessoa, empresa ou organização.

Entre em contato com a livraria:

Livraria Central
Rua das Letras, 45
São Paulo - SP
contato@livrariacentral.com.br

Tag <blockquote>

Marca uma citação longa, exibida em um bloco separado do texto.

A prática constante é o melhor caminho para aprender.

Tag <q>

Marca uma citação curta dentro do texto. O navegador adiciona as aspas.

Minha avó sempre dizia devagar é que se chega longe.
