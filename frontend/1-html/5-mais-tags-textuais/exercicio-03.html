Tag <sub> (Subscrito)

A tag <sub> reduz o tamanho da fonte e desloca o texto para baixo em relação à linha base do texto.

Uso comum: fórmulas químicas. Exemplo: H2O (água).

Fórmulas do dióxido de carbono: CO 2.

Fórmula do ácido sulfúrico: H2SO4.

Tag <sup> (Sobrescrito)

A tag <sup> reduz o tamanho da fonte e desloca o texto para cima em relação à linha base do texto.

Uso comum: expoentes matemáticos. Exemplo: x2 (x ao quadrado).

Equação: 23 = 8.

Teorema de Pitágoras: a2 + b2 = c2.

Nota prática: Use <sub> para caracteres inferiores (base de fórmulas). Use <sup> para caracteres superiores (expoentes e ordinais, como 1o).
