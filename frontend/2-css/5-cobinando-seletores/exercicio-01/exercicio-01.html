Seletor Descendente (espaço)

Sintaxe: pai descendente { propriedade: valor; }
O seletor descendente (espaço) seleciona TODOS os elementos que estão dentro do pai, em qualquer nível de aninhamento (filho, neto, bisneto...).

Exemplo 1: .container p

Este parágrafo é filho direto de .container — será estilizado.

Este parágrafo está dentro de uma div interna (neto de .container) — também será estilizado, pois é descendente!

Este está dentro de section > article (bisneto) — o seletor descendente também alcança ele.

Aqui temos um SPAN destacado dentro de um parágrafo. O seletor .container p span encontrou e estilizou ele.

Note que TODOS os parágrafos dentro de .container foram afetados, não importa o quão fundo estejam.

Exemplo 2: #menu-principal li

  • Início — este item ganhou cor e borda
  • Sobre — o strong dentro dele também ficou verde (regra 4)
  • Serviços
    • Consultoria — este é neto do #menu-principal, mas o seletor descendente #menu-principal li também pegou ele!
    • Suporte — mesmo estando dentro de outra lista, continua sendo descendente.
  • Contato — outro item

Observe que os <li> dentro da sub-lista (nível 2) também ganharam o estilo, porque são descendentes de #menu-principal.

Exemplo 3: .destaque a

Este é um link dentro de .destaque: Clique aqui — ele foi estilizado.

Outro link dentro de uma div aninhada: Link interno — também foi estilizado, pois é descendente de .destaque.

Já este link fora do .destaque NÃO recebeu o estilo, porque não é descendente.

Para fixar: Descendente vs Filho

Descendente (espaço): .box p → pega todos os <p> dentro de .box, em qualquer profundidade.

Filho (>): .box > p → pega apenas os <p> que são filhos diretos (primeiro nível) de .box.

No Exemplo 1, se usássemos .container > p, apenas o PRIMEIRO parágrafo (o filho direto) seria estilizado. Os outros (dentro de div, section, article) seriam ignorados. Com o descendente (espaço), TODOS foram estilizados.

Fim do exemplo — Seletor descendente ( ) aplicado em várias situações.
