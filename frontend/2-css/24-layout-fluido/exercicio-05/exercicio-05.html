Flow Layout

Antes de float, flexbox ou grid existe o fluxo normal. É o jeito padrão de o navegador dispor a página: elementos de bloco empilham de cima para baixo; elementos inline fluem lado a lado e quebram de linha quando o espaço acaba.

2 — Inlines fluem lado a lado

Neste parágrafo, os trechos destacados são inline: inline 01 e inline 02 não abrem linha nova. Eles se encaixam na sequência do texto, inline 03 continua ocupando a mesma linha até ela ficar cheia. Quando isso acontece, inline 04 simplesmente escorre para a linha seguinte, e o texto segue: inline 05, sem nenhuma regra extra de layout.

Span, strong, em, links e o próprio texto são inline: dividem a mesma linha enquanto houver espaço.
