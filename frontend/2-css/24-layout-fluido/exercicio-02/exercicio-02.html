A Gazeta das Colunas

Um texto único, sem nenhuma divisão no HTML, repartido em colunas diretamente pelo CSS.

Duas colunas com column-count

Um texto só, duas colunas

No HTML, este artigo é apenas uma sequência de parágrafos, um depois do outro, como qualquer texto comum. Não existe coluna marcada na estrutura: nenhuma tabela, nenhuma divisão lateral.

Quem cria as colunas é o CSS. Ao receber column-count: 2, o navegador mede todo o conteúdo, divide em duas partes de altura parecida e deposita uma parte em cada coluna.

Se um parágrafo cai exatamente na fronteira, ele é cortado e continua na coluna seguinte, como acontece em jornais e revistas.

column-count: 2 — o número de colunas é fixo; a altura de cada uma é calculada pelo navegador.

Três colunas com column-gap e column-rule

Agora pedimos três colunas. O conteúdo continua sendo o mesmo tipo de coisa: parágrafos comuns que o navegador distribui, um trecho por coluna, até preencher as três.

O column-gap abre um respiro entre as colunas. Sem ele, elas ficam coladas e a leitura fica cansativa, porque o olho tropeça ao saltar de uma para a outra.

Já o column-rule desenha um filete vertical no meio do vão. Ele é apenas decorativo: não ocupa espaço que pertenceria ao texto, apenas aparece dentro do gap.

É por isso que esta seção parece uma página de jornal: todo o efeito visual nasce de poucas propriedades aplicadas a um único elemento.

column-count: 3 · column-gap: 1.8rem · column-rule: 1px solid

Colunas por largura com column-width

Nesta última demonstração não pedimos um número de colunas. Pedimos uma largura: column-width: 170px.

Com isso, o navegador faz uma conta simples: verifica quantas colunas de 170px cabem na largura disponível e cria tantas quantas couberem. Se o container for mais largo, surgem mais colunas; se for mais estreito, menos.

Este é o único momento em que a quantidade de colunas não está escrita no CSS — ela nasce do espaço disponível.

column-width: 170px — o número de colunas é consequência do espaço.
