position: sticky

Flui normalmente — até atingir o limite. Aí gruda.

Age como relative no início. Quando a rolagem atinge o threshold definido (top: 0 aqui), o elemento gruda — mas só enquanto o pai ainda estiver visível. Quando o pai vai embora, ele vai junto.

01 Fundamentos — como o sticky funciona
O sticky age como relative até atingir o threshold. Aqui o threshold é top: 0 — a borda do viewport.
Quando o header toca o topo da janela, ele "gruda" e fica lá. Diferente do fixed, ele não fica para sempre.
O sticky só funciona se o pai tiver altura suficiente para o filho ter onde "andar" antes de grudar. Sem altura no pai, nada acontece.
Cuidado com overflow: hidden no pai ou em qualquer ancestral — isso quebra o sticky silenciosamente.
Sempre combine com z-index pra garantir que o header fique por cima do conteúdo que passa embaixo dele.
Suportado em todos os browsers modernos. Não precisa de prefixo (-webkit-) há alguns anos já.
02 Comportamento — o que acontece na transição
Quando a seção anterior termina, o header "02" empurra o "01" pra cima e toma o lugar dele no topo. Observe esse momento.
Esse comportamento é diferente do fixed: dois elementos fixed no mesmo top: 0 se sobrepõem. Dois sticky se empurram.
O sticky mantém o ritmo do scroll. Quando a seção termina, o header sai de cena naturalmente — sem um "salto" visual brusco.
Esse padrão é muito comum em FAQs, tabelas de conteúdo, listas longas com categorias, e sidebars de documentação.
O threshold não precisa ser top: 0. Poderia ser top: 80px se houvesse uma navbar fixed de 80px ocupando o topo.
Inspecione um dos headers no DevTools e veja a propriedade position: sticky aplicada.
03 Casos de uso — onde sticky brilha
Tabelas com cabeçalho fixo: o thead fica visível enquanto você rola pelas linhas de dados.
Sidebars que acompanham a leitura: o índice lateral gruda enquanto você lê o artigo, some quando passa da seção.
Filtros de e-commerce que ficam no topo da lista de produtos enquanto você rola os resultados.
Letras de agrupamento (A, B, C...) em listas de contatos — o padrão que o iOS e Android usam na lista de apps.
Barras de progresso de leitura por seção — cada header marca o início de um bloco novo de conteúdo.
Resumo: sempre que você quiser que algo grude temporariamente — e não para sempre — sticky é a ferramenta certa.
