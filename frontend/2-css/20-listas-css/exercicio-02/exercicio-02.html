Exercicio 02: Glifos Fundamentais com list-style-type

Comparacao entre os valores fundamentais da especificacao para listas nao ordenadas.

list-style-type: disc (Padrao)

  • Grao de cafe arabica
  • Grao de cafe robusta

list-style-type: circle

  • Secagem em terreiro suspenso
  • Fermentacao natural controlada

list-style-type: square

  • Torra clara artesanal
  • Torra media uniforme

list-style-type: none

  • Moagem media sem bullet visual
  • Extracao por infusao sem glifo
