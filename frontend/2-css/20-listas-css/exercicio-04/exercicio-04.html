Exercicio 04: Marcadores com String Literal

O CSS Lists 3 permite passar qualquer sequencia de caracteres diretamente para list-style-type.

Marcador com seta: "— "

  • Identificacao de especies botanicas
  • Coleta de amostras de solo

Marcador com simbolo: "✔ "

  • Catalogo de sementes nativas
  • Germinacao em estufa protegida

Marcador textual: "Item: "

  • Registro de biomassa florestal
  • Monitoramento hidrico do dossel
