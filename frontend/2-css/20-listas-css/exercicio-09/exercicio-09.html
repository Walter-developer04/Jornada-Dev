Exercicio 09: Atributos HTML de Ordenacao

Integracao entre os atributos semanticos start, reversed e value com os contadores de renderizacao.

Lista Invertida: reversed

  1. Lancamento da sonda orbital
  2. Verificacao de telemetria
  3. Ignicao dos propulsores

Inicio Deslocado: start="10"

  1. Modulo de observacao termica
  2. Modulo de transmissao espectral

Salto Pontual de Valor: li value="50"

  1. Parametro inicial regular
  2. Parametro com salto semantico para 50
  3. Sequencia subsequente automatica
