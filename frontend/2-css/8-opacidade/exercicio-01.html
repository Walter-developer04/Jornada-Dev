Opacidade no CSS

Entenda como a propriedade opacity controla a transparência de um elemento — da escala de 0 a 1 ao efeito sobre o seu conteúdo.

0 = totalmente transparente · 1 = totalmente opaco

01

O que é opacity

opacity é a propriedade do CSS que controla o nível de opacidade de um elemento: o quanto ele permite ver o que está atrás dele. O valor é sempre um número entre 0 e 1.

opacity: 1;

Totalmente opaco: o elemento cobre por completo o que está atrás dele.

opacity: 0.5;

Meio transparente: o fundo aparece parcialmente através do elemento.

opacity: 0;

Totalmente transparente: o elemento fica invisível — mas continua lá.

02

03

Como escrever opacity

Uma regra com opacity tem a mesma estrutura de qualquer regra CSS: um seletor, uma propriedade e um valor. 

.elemento {
    opacity: 0.5;
}

  • Seletor — indica a qual elemento a regra se aplica.

  • Propriedade — o que será ajustado: a opacidade.

  • Valor — quanto de opacidade, de 0 a 1.

O valor é apenas um número: ele não leva unidade, como px ou em.

04

Opacity afeta o elemento inteiro

A opacidade vale para o elemento como um todo. Quando você aplica opacity em uma caixa, o fundo, as bordas e também todo o conteúdo de dentro — texto, imagens, outros elementos — ficam transparentes juntos. Compare duas caixas iguais:

Uma caixa com texto

Fundo e texto totalmente opacos.

opacity: 1;

Uma caixa com texto

Com opacity: 0.35, o texto fica translúcido junto com o fundo.

opacity: 0.35;

05

Opacity x transparência de uma cor

Existe outro jeito de criar transparência: declarar uma cor com canal alfa, como em rgb(36 92 99 / 50%). O fundo fica parecido, mas o efeito não é o mesmo. Veja as duas caixas com texto dentro:

A caixa inteira

Com opacity: 0.5, fundo e texto ficam translúcidos juntos.

opacity: 0.5;

Apenas o fundo

Com o alfa na cor de fundo, o texto continua totalmente opaco.

background-color: rgb(36 92 99 / 50%);

Resumindo: opacity afeta o elemento inteiro, conteúdo incluído. Já o canal alfa deixa transparente somente a cor em que é declarado — neste exemplo, apenas o fundo da caixa.

06

opacity: 0

Com opacity: 0, o elemento fica totalmente transparente: invisível. Isso não significa que ele deixou de existir — ele continua no documento e continua ocupando o seu espaço no layout.

opacity: 0 no quadrado do meio

Ele fica invisível, mas o lugar dele continua reservado.

display: none no quadrado do meio

O quadrado some, e o espaço dele também: os vizinhos se encostam.

Por isso as duas declarações não são equivalentes: opacity: 0 apenas torna o elemento invisível; display: none faz o elemento nem ser renderizado — sem caixa e sem espaço ocupado.

07

Uso prático: opacidade no hover

Um uso comum de opacity é dar um retorno visual quando o ponteiro passa por cima de um elemento. Passe o mouse (ou toque) nos botões abaixo: 

.botao-demo {
    transition: opacity 0.3s;
}

.botao-demo:hover {
    opacity: 0.6;
}

Sem a transition, a mudança seria instantânea. Com transition: opacity 0.3s, ela acontece de forma suave, ao longo de 0.3 segundos.
