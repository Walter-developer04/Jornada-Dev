LINE-
HEIGHT

A altura da caixa de linha: o espaço vertical entre as linhas do seu texto.

01 O que é ?

A propriedade line-height define a altura da caixa de linha (line box). Em elementos de bloco, ela determina a altura mínima das caixas de linha dentro do elemento; em texto inline, é a altura usada no cálculo da altura de cada linha.

Na prática: line-height controla o "respiro" vertical do texto, sem alterar o tamanho da fonte em si.

p { line-height: 1.5; }

02 Valores possíveis

normal
Valor inicial. Depende do navegador — a maioria dos agentes aplica algo próximo de 1,2.
1.5 — número puro (sem unidade)
Multiplicado pelo font-size do próprio elemento. É o valor recomendado pela documentação, pois os filhos herdam o fator e recalculam com o próprio tamanho de fonte.
1.5em ou 24px — comprimento
Altura de linha fixa, computada no elemento onde foi declarada.
150% — porcentagem
Percentual do font-size do elemento. Atenção: os filhos herdam o valor já calculado, não a porcentagem.

03 Demonstração

Cada faixa clara no parágrafo abaixo marca a altura de uma caixa de linha. Aperte o botão para alternar entre valores de line-height e observe o espaço vertical mudar — a fonte permanece exatamente a mesma.

Este parágrafo é o campo de prova. Cada faixa que você vê marca a altura de uma linha, a tal line box. Aperte o botão e observe o espaço vertical entre as linhas crescer e encolher, enquanto o tamanho da fonte não muda nem um pixel.

line-height: 1.2; — normal (padrão do navegador)

04 Dica de herança

Prefira o número sem unidade. Com line-height: 1.5, cada elemento descendente recalcula a altura a partir do seu próprio font-size. Com 1.5em ou 150%, os filhos herdam um valor já resolvido em pixels — o que pode apertar linhas de texto menores que o esperado.
