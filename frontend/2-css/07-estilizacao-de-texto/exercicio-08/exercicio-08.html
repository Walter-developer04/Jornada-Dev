O que é text-shadow

A propriedade text-shadow adiciona uma ou mais sombras ao texto de um elemento. Ela permite controlar a posição, o desfoque e a cor de cada sombra.

A sombra pode ser deslocada horizontalmente e verticalmente em relação ao texto. Também é possível definir um valor de desfoque para criar uma aparência mais suave.

A propriedade pode ser utilizada para criar efeitos simples ou mais elaborados, como profundidade, contorno, destaque, brilho e diferentes níveis de contraste.

A sintaxe

Uma sombra pode ser definida utilizando deslocamento horizontal, deslocamento vertical, desfoque e cor:

/*       x    y  desfoque  cor */
text-shadow: 4px 4px 2px #b65a4a;

/* somente os deslocamentos */
text-shadow: 4px 4px;
Os principais valores de uma sombra
Parte O que faz Observação
offset-x Define o deslocamento horizontal da sombra. Valor negativo desloca a sombra para a esquerda.
offset-y Define o deslocamento vertical da sombra. Valor negativo desloca a sombra para cima.
blur Define o nível de desfoque da sombra. Quanto maior o valor, mais suave será a sombra.
cor Define a cor da sombra. Quando omitida, a sombra utiliza a cor atual do texto.

Exemplos de text-shadow

A propriedade pode produzir diferentes resultados dependendo dos valores utilizados. Observe o efeito visual e o código responsável por cada exemplo.

Nº 1 · Sombra sem desfoque

SOMBRA

Sem desfoque, a sombra apresenta bordas definidas e um efeito mais sólido.

text-shadow: 5px 5px 0 #b65a4a;

Nº 2 · Sombra suave

SUAVE

O valor de desfoque suaviza as bordas e cria uma sombra menos definida.

text-shadow: 3px 4px 9px rgba(47,42,36,.5);

Nº 3 · Destaque

DESTAQUE

Uma sombra com pouco deslocamento pode criar contraste e destacar o texto.

text-shadow: 0 2px 0 #e7c9a9;

Nº 4 · Profundidade

RELEVO

Várias sombras próximas podem ser combinadas para produzir um efeito de profundidade.

text-shadow: 1px 1px 0 #b65a4a, 2px 2px 0 #b65a4a, 3px 3px 0 #b65a4a, 4px 4px 0 #b65a4a, 5px 5px 0 #b65a4a, 6px 6px 0 #2f2a24;

Nº 5 · Contorno

CONTORNO

Sombras em diferentes direções podem criar um contorno ao redor das letras.

text-shadow: -2px 0 0 #2f2a24, 2px 0 0 #2f2a24, 0 -2px 0 #2f2a24, 0 2px 0 #2f2a24, -2px -2px 0 #2f2a24, 2px 2px 0 #2f2a24, -2px 2px 0 #2f2a24, 2px -2px 0 #2f2a24;

Nº 6 · Duas sombras

CAMADAS

É possível adicionar mais de uma sombra ao mesmo texto, separando cada uma por vírgula.

text-shadow: 4px 4px 0 #6b7d5a, 8px 8px 0 #2f2a24;

Nº 7 · Brilho

BRILHO

Quando não há deslocamento e existe bastante desfoque, a sombra pode criar um efeito de brilho.

text-shadow: 0 0 18px rgba(213,139,106,.6);

Múltiplas sombras

A propriedade text-shadow permite adicionar várias sombras ao mesmo texto. Cada sombra deve ser separada por uma vírgula. 

text-shadow:
  3px 3px 0 #b65a4a,
  14px 16px 20px rgba(47,42,36,.8);

A combinação de diferentes valores permite criar efeitos de profundidade, contorno, relevo e brilho utilizando apenas CSS.

Dicas importantes

Alguns pontos importantes para utilizar text-shadow corretamente:

  • Várias sombras podem ser declaradas em uma única propriedade, separadas por vírgulas.
  • A cor da sombra pode ser definida explicitamente ou omitida, permitindo que ela utilize a cor atual do texto.
  • O valor de desfoque não pode ser negativo. Já os deslocamentos podem utilizar valores positivos ou negativos.
  • A sombra não ocupa espaço no fluxo do documento, pois é um efeito visual aplicado ao texto.
  • O excesso de sombra pode prejudicar a leitura. Utilize contraste e desfoque de forma equilibrada.
  • text-shadow: none; remove as sombras aplicadas ao texto.

Use text-shadow para complementar o texto, mantendo o efeito visual equilibrado e a leitura confortável.
