Exercício 01

CSS Variables: declarar uma vez, usar em vários lugares

Uma propriedade personalizada guarda um valor com nome. Qualquer elemento pode consumir esse valor com var().

1. Declaração no escopo global

O seletor :root define valores disponíveis para toda a página. O nome de uma variável sempre começa com dois hifens.

  • --cor-principal #1f5d50
  • --cor-secundaria #b84a32
  • --cor-destaque #e3b23c

2. Consumo com var()

Nenhum dos quatro exemplos abaixo repete um código de cor. Cada um apenas pede o valor pelo nome da variável.

  • Cor do texto

    Texto na cor principal

    color: var(--cor-principal);

  • Cor de fundo

    Fundo na cor secundária

    background-color: var(--cor-secundaria);

  • Cor da borda

    Borda na cor principal

    border: 2px solid var(--cor-principal);

  • Cor de destaque

    Fundo na cor de destaque

    background-color: var(--cor-destaque);

3. Onde cada variável aparece nesta página

--cor-principal
Título principal, etiqueta do exercício, linhas sob os subtítulos, texto do primeiro exemplo e borda do terceiro.
--cor-secundaria
Nomes das variáveis e fundo do segundo exemplo.
--cor-destaque
Faixa lateral do cabeçalho e fundo do quarto exemplo.

As amostras de cor da seção 1 e as etiquetas desta lista também consomem as mesmas três variáveis. Alterar um valor em :root atualiza todos esses pontos de uma só vez.
