Exercício 03 · CSS Functions

var(): um valor, vários usos

Uma custom property guarda um valor uma vez. A função var() o reutiliza onde for preciso.

Demonstração

:root {
    --cor-destaque: #F6D488;
    --espaco: 1.5rem;
}
.cartao-constelacao { border: 3px solid var(--cor-destaque); }

Cartão A

Valor herdado de :root

Borda sólida usando --cor-destaque.

Cartão B

Valor redefinido no cartão

Borda dupla: a mesma regra, mas --cor-destaque vale outra cor aqui dentro.

Cartão C

Valor reserva

Borda tracejada: var(--cor-inexistente, #FFFFFF) usa o segundo valor porque a variável não existe.

Análise

  • Problema: a mesma cor se repete em várias regras.
  • Função: var() lê a custom property no ponto onde é usada.
  • Resultado: trocar o valor em um lugar atualiza todos os usos.
  • Escopo: uma custom property pode ser redefinida dentro de um elemento e vale para os seus descendentes.

Validação

  • Manutenção: poucas variáveis, com nomes claros. Criar dezenas sem necessidade só piora a leitura.
  • Accessibility: texto #EEF1FF sobre fundo #05060F tem contraste muito acima de 4,5:1 (WCAG 1.4.3). Ao trocar uma variável de cor, o contraste precisa ser verificado de novo.
  • Performance: alterar uma variável pode exigir recálculo de estilo nos elementos que a usam. Com poucas variáveis, como aqui, o custo tende a ser pequeno.
  • Compatibilidade: consulte a tabela de var() no MDN; versões não foram verificadas neste exercício.
