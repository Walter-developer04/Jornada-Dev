Exercício 02 · CSS Functions

min(), max() e clamp()

Três funções para limitar um valor que muda com a janela: teto, piso e os dois juntos.

Demonstração

Todas as barras partem de 45vw. Redimensione a janela e compare o comportamento de cada uma.

  • sem função: width: 45vw
  • min(): width: min(45vw, 24rem)
  • max(): width: max(45vw, 12rem)
  • clamp(): width: clamp(12rem, 45vw, 24rem)

Análise

min()

Escolhe o menor valor da lista. Funciona como teto: a barra cresce, mas para em 24rem.

max()

Escolhe o maior valor. Funciona como piso: a barra nunca fica menor que 12rem.

clamp()

Recebe mínimo, valor ideal e máximo. Equivale a max(mínimo, min(ideal, máximo)).

Validação

Este texto usa clamp(1rem, 0.9rem + 1vw, 1.5rem).

  • Accessibility: o mínimo e o ideal usam rem, então o texto continua respondendo à ampliação do usuário (WCAG 1.4.4). Evite font-size apenas com vw.
  • Performance: estas funções podem substituir media queries simples e reduzir CSS. Isso melhora a manutenção; não é garantia de renderização mais rápida.
  • Compatibilidade: segundo os dados de compatibilidade do MDN, clamp() é suportada desde Chrome e Edge 79, Firefox 75 e Safari 13.1. Para min() e max(), consulte a tabela do MDN.
