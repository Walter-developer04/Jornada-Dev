Arquivo 04 · Best Practices

Caso 04: o CSS suspeito

Funcionar não significa estar bem implementado. A investigação compara duas soluções que produzem um resultado parecido.

Confidencial

Evidências

Evidência A — decisão ruim

Amostra A
border-top: 2px solid #1C1A17;
border-right: 2px solid #1C1A17;
border-bottom: 2px solid #1C1A17;
border-left: 2px solid #1C1A17;
box-shadow:
  0 0 40px rgba(0,0,0,.4),
  0 0 80px rgba(0,0,0,.4),
  0 0 120px rgba(0,0,0,.4);

Evidência B — decisão melhor

Amostra B
border: 2px solid #1C1A17;
box-shadow: 0 0.25rem 0.75rem rgba(0,0,0,.25);

Análise

  • Decisão: ambas as soluções funcionam e entregam um bloco com borda e sombra.
  • Avaliação: A repete quatro bordas iguais e empilha três sombras com desfoque grande. Sombras amplas podem aumentar o trabalho de pintura.
  • Conclusão: B declara a borda uma vez e usa uma sombra. Essa abordagem pode reduzir trabalho desnecessário em determinadas situações e é mais fácil de manter.

Como verificar

  1. Abra as ferramentas do desenvolvedor do navegador.
  2. Use o painel Performance para gravar e observar as etapas de estilo, layout e pintura.
  3. No Chrome, ative Paint flashing no painel Rendering para ver as áreas repintadas.
  4. Compare as duas versões antes de concluir. Nenhuma técnica é sempre mais rápida; meça o caso real.

Accessibility: tinta #1C1A17 sobre papel #E8DCC0 mantém contraste alto, e as evidências são identificadas por texto e estilo de borda, não só por cor.
