Exercicio 03: Especificidade: ID vs. Múltiplas Classes

Um ID (1-0-0) tem mais peso que qualquer combinação de classes

Demonstracao

Elemento com ID e 3 classes. O ID vence.

Tres classes somam 0-3-0, mas um ID (1-0-0) ainda vence.

Regras CSS aplicadas

.classe-a.classe-b.classe-c { color: #e53e3e; } #principal { color: #d69e2e; }

Teste

Abra o DevTools (F12) e inspecione o elemento para ver qual regra esta sendo aplicada.

Tente remover ou comentar regras no arquivo CSS para ver a diferenca.
