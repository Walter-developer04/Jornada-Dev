Exercicio 04: Especificidade: Seletores de Atributo

Seletores de atributo (0-1-0) têm peso igual a classes

Demonstracao

input[type=text] tem especificidade 0-1-1. Com classe, vira 0-2-1.

Regras CSS aplicadas

input[type='text'] { border: 2px solid #e53e3e; padding: 10px; } input[type='text'].campo-texto { border: 2px solid #38a169; padding: 12px; }

Teste

Abra o DevTools (F12) e inspecione o elemento para ver qual regra esta sendo aplicada.

Tente remover ou comentar regras no arquivo CSS para ver a diferenca.
