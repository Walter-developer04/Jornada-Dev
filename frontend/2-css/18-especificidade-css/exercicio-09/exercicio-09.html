Exercicio 09: Estilos Inline vs. Stylesheet

Estilos inline têm prioridade sobre qualquer seletor CSS (mas !important pode vencer)

Demonstracao

Este paragrafo tem estilo inline e classe CSS.

Inline vence classe CSS. Mas !important na folha de estilo vence inline (se o inline não tiver !important).

Regras CSS aplicadas

.classe-css { color: #e53e3e !important; font-size: 14px; }

Teste

Abra o DevTools (F12) e inspecione o elemento para ver qual regra esta sendo aplicada.

Tente remover ou comentar regras no arquivo CSS para ver a diferenca.
