Exercicio 10: Especificidade: !important

!important muda a origem da cascata (não é especificidade), mas quando ambos são !important, a especificidade decide

Demonstracao

Elemento com ID e classe, ambos com !important.

Ambos sao !important. ID (1-0-0) vence classe (0-1-0).

Regras CSS aplicadas

#um { color: #38a169 !important; } .dois { color: #e53e3e !important; }

Teste

Abra o DevTools (F12) e inspecione o elemento para ver qual regra esta sendo aplicada.

Tente remover ou comentar regras no arquivo CSS para ver a diferenca.
