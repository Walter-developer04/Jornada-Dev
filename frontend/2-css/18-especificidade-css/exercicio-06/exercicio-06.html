Exercicio 06: Especificidade: Pseudo-elementos

Pseudo-elementos como ::before (0-0-1) têm peso igual a seletores de tipo

Demonstracao

Este paragrafo tem um pseudo-elemento ::before.

p::before tem 0-0-2. Com classe, vira 0-1-2.

Regras CSS aplicadas

p::before { content: '>>> '; color: #e53e3e; } p.com-before::before { content: '*** '; color: #38a169; }

Teste

Abra o DevTools (F12) e inspecione o elemento para ver qual regra esta sendo aplicada.

Tente remover ou comentar regras no arquivo CSS para ver a diferenca.
