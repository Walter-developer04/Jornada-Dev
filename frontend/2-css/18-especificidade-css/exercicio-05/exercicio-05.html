Exercicio 05: Especificidade: Pseudo-classes

Pseudo-classes como :hover (0-1-0) têm peso igual a classes

Demonstracao

Passe o mouse aqui

a:hover tem 0-1-1. Com classe adicional, vira 0-2-1.

Regras CSS aplicadas

a:hover { color: #dd6b20; } a:hover.link-especial { color: #805ad5; text-decoration: none; }

Teste

Abra o DevTools (F12) e inspecione o elemento para ver qual regra esta sendo aplicada.

Tente remover ou comentar regras no arquivo CSS para ver a diferenca.
