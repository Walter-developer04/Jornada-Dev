Exercicio 01: Cálculo Básico de Especificidade

A hierarquia ID (1-0-0) > Classe (0-1-0) > Elemento (0-0-1)

Demonstracao

Texto com ID e classe. Veja qual regra vence.

ID vence sobre classe, que vence sobre elemento. A especificidade e calculada como (ID, Classe, Elemento).

Regras CSS aplicadas

p { color: #e53e3e; } .alvo-classe { color: #3182ce; } #alvo-id { color: #38a169; }

Teste

Abra o DevTools (F12) e inspecione o elemento para ver qual regra esta sendo aplicada.

Tente remover ou comentar regras no arquivo CSS para ver a diferenca.
