Exercicio 08: Especificidade: :where()

:where() sempre tem especificidade zero (0-0-0), independente dos argumentos

Demonstracao

Paragrafo com :where() aplicado. O seletor p simples vence.

:where() sempre tem especificidade 0-0-0, mesmo com ID dentro. O seletor p (0-0-1) vence.

Regras CSS aplicadas

:where(#especial, .classe, p) { color: #e53e3e; font-size: 20px; } p { color: #38a169; font-size: 16px; }

Teste

Abra o DevTools (F12) e inspecione o elemento para ver qual regra esta sendo aplicada.

Tente remover ou comentar regras no arquivo CSS para ver a diferenca.
