Exercicio 02: Especificidade: Tipo vs. Classe

Um seletor de classe (0-1-0) tem mais peso que um seletor de tipo (0-0-1)

Demonstracao

Este paragrafo tem classe. A classe vence o seletor de elemento.

Este paragrafo nao tem classe. Recebe o estilo do elemento p.

A classe .destaque tem especificidade 0-1-0, maior que p (0-0-1).

Regras CSS aplicadas

p { color: #e53e3e; font-size: 18px; } .destaque { color: #805ad5; font-size: 22px; }

Teste

Abra o DevTools (F12) e inspecione o elemento para ver qual regra esta sendo aplicada.

Tente remover ou comentar regras no arquivo CSS para ver a diferenca.
