Exercicio 07: Especificidade: :is(), :not(), :has()

Herdam a especificidade do argumento mais específico dentro delas

Demonstracao

Paragrafo normal

Div com ID especial

:is(p, #especial) tem especificidade 1-0-0 (do ID), vencendo p (0-0-1).

Regras CSS aplicadas

:is(p, #especial) { color: #3182ce; font-weight: bold; } p { color: #e53e3e; }

Teste

Abra o DevTools (F12) e inspecione o elemento para ver qual regra esta sendo aplicada.

Tente remover ou comentar regras no arquivo CSS para ver a diferenca.
