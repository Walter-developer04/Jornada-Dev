font-variant

A propriedade font-variant permite definir diferentes variações tipográficas para um texto. Ela é uma propriedade abreviada que reúne várias configurações relacionadas às características da fonte.

O que é font-variant

font-variant é uma propriedade CSS usada para controlar determinadas características tipográficas de uma fonte.

Diferentemente de propriedades como font-size e font-weight, que controlam diretamente o tamanho e o peso do texto, font-variant trabalha com recursos tipográficos oferecidos pela fonte.

A propriedade pode receber diferentes valores e também pode combinar mais de uma variação.

font-variant: normal

O valor normal mantém as variações tipográficas em seu estado normal.

Exemplo

p {
  font-variant: normal;
}

Resultado

Texto utilizando font-variant normal.

font-variant: small-caps

O valor small-caps exibe as letras minúsculas como pequenas versões de letras maiúsculas. As letras que já são maiúsculas continuam sendo exibidas como maiúsculas.

Exemplo

p {
  font-variant: small-caps;
}

Resultado

Este texto utiliza small-caps para alterar a apresentação das letras.

Small caps na prática

O efeito pode ser utilizado em títulos, nomes ou pequenos trechos de texto quando se deseja uma aparência semelhante às letras maiúsculas, mas mantendo uma diferença visual de tamanho.

Outras variações

A propriedade font-variant também pode controlar outros recursos tipográficos. Entre eles estão variações de ligaturas, maiúsculas, números e formas de caracteres.

Alguns desses recursos podem ser definidos diretamente por valores de font-variant, enquanto outros também possuem propriedades específicas, como font-variant-caps, font-variant-numeric e font-variant-ligatures.

font-variant e suas propriedades específicas

Como font-variant é uma propriedade abreviada, ela reúne configurações de outras propriedades relacionadas às variantes das fontes.

Entre essas propriedades estão font-variant-caps, font-variant-numeric, font-variant-ligatures, font-variant-alternates, font-variant-east-asian, font-variant-position e font-variant-emoji.

Neste momento, não é necessário estudar todas essas propriedades separadamente. O mais importante é entender que font-variant funciona como uma forma abreviada de definir diferentes variantes tipográficas.

Mais de uma variação

Alguns valores de font-variant podem ser combinados na mesma declaração.

Por exemplo, a propriedade pode receber small-caps junto com uma configuração relacionada aos números.

Exemplo

p {
  font-variant: small-caps tabular-nums;
}

Resultado

Valores 2026 1234 5678 e texto com small caps.

font-variant e a fonte utilizada

O resultado das variações tipográficas depende dos recursos disponíveis na fonte utilizada. Nem toda fonte possui suporte para todas as características tipográficas.

Por isso, uma declaração de font-variant pode produzir resultados diferentes dependendo da fonte utilizada e do recurso escolhido.

Exemplo final

O exemplo abaixo reúne uma fonte e uma variação tipográfica em uma mesma regra CSS.

p {
  font-family: "Roboto", sans-serif;
  font-variant: small-caps;
}

Este texto utiliza a fonte Roboto com a variação small-caps.

Resumo

font-variant é uma propriedade abreviada do CSS usada para definir variantes tipográficas de uma fonte.

O valor normal mantém as configurações normais. O valor small-caps cria uma apresentação em pequenas maiúsculas. Também existem valores relacionados a ligaturas, números, formas de caracteres e outras características tipográficas.

A propriedade pode receber mais de uma variação e reúne configurações que também podem ser controladas por propriedades específicas font-variant-*.
