A abreviação font

Em CSS, font é uma abreviação (shorthand): uma única declaração que reúne sete propriedades tipográficas. Em vez de espalhar estilo, peso, tamanho e família pela folha de estilo, você escreve tudo de uma vez.

A ordem importa

A sintaxe segue uma sequência fixa: o que vem antes do tamanho é opcional; tamanho e família são obrigatórios.

font: [style] [variant] [weight] [stretch] size[/line-height] family;

Sete linhas viram uma

O caminho longo:

font-style: italic;
font-variant: small-caps;
font-weight: 700;
font-stretch: normal;
font-size: 1.5rem;
line-height: 1.5;
font-family: "Fraunces", Georgia, serif;

Equivale exatamente a:

font: italic small-caps 700 1.5rem/1.5 "Fraunces", Georgia, serif;

Repare: a altura de linha vem sempre colada ao tamanho, separada por uma barra.

Vendo acontecer

O parágrafo abaixo usa a declaração acima, ao vivo:

A tipografia é a voz do texto — e uma única linha de CSS ajusta o tom, o peso e o ritmo com que cada palavra é dita.

Atenção: sem font-size e font-family, o navegador descarta a declaração inteira.

Use a abreviação para definir uma tipografia do zero; para ajustar, prefira as propriedades individuais — a abreviação zera tudo o que você omite: font: 1rem serif apaga o peso e o estilo que o elemento carregava, e mudar um único valor obriga a reescrever a linha inteira.
