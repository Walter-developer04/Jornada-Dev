Google Fonts

O Google Fonts é um serviço que disponibiliza diferentes fontes tipográficas para serem utilizadas em páginas da web. Neste exercício, vamos conhecer sua finalidade e entender como uma fonte pode ser aplicada com CSS.

O que é o Google Fonts

O Google Fonts é uma biblioteca de fontes disponibilizada pelo Google. Ela permite que desenvolvedores escolham diferentes famílias tipográficas para utilizar em seus sites.

Entre as fontes disponíveis estão famílias como Roboto, Open Sans, Lato e Montserrat.

O que são fontes tipográficas

Uma fonte tipográfica é um conjunto de caracteres que possui determinado estilo visual. Ela define a aparência das letras, números e outros símbolos utilizados em um texto.

A escolha da fonte pode influenciar a aparência e a leitura de uma página. Por isso, a tipografia é uma parte importante da apresentação de um site.

Para que o Google Fonts serve

Um site pode utilizar fontes que já estão instaladas no computador ou dispositivo do usuário. Porém, nem todas as fontes estão disponíveis em todos os dispositivos.

O Google Fonts oferece uma alternativa para utilizar outras famílias de fontes em uma página web. A fonte escolhida pode ser carregada pela página e depois utilizada pelo CSS.

Como adicionar uma fonte

Para utilizar uma fonte do Google Fonts, podemos adicionar uma tag <link> dentro do elemento <head> do documento HTML.

Nesta página, a fonte escolhida foi a Roboto. O código utilizado para carregá-la é fornecido pelo próprio Google Fonts. 

<link
  href="https://fonts.googleapis.com/css2?family=Roboto:wght@400;700&display=swap"
  rel="stylesheet"
>

Como aplicar a fonte com CSS

Depois que a fonte é adicionada à página, podemos utilizá-la com a propriedade font-family. 

body {
  font-family: "Roboto", sans-serif;
}

Nesse exemplo, Roboto é a fonte principal. O valor sans-serif funciona como uma opção de reserva caso a Roboto não possa ser utilizada.

Também podemos utilizar a propriedade font-weight para definir o peso do texto. Neste exercício, foram carregados os pesos 400 e 700 da Roboto.

HTML, CSS e Google Fonts

O HTML organiza o conteúdo da página, como títulos e parágrafos. O CSS controla a aparência desses elementos, incluindo a escolha da fonte.

O Google Fonts fornece a fonte que será utilizada. Depois de carregada, ela pode ser aplicada aos elementos HTML por meio do CSS.

O Google Fonts disponibiliza diversas famílias de fontes para utilização em páginas web. Uma fonte pode ser adicionada ao HTML por meio de uma tag <link> e aplicada pelo CSS utilizando font-family.
