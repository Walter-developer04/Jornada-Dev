Seletor Irmão Subsequente (~)

Sintaxe: elemento1 ~ elemento2 { propriedade: valor; }
Seleciona todos os elementos que vêm depois de um determinado elemento, desde que compartilhem o mesmo pai. (Não precisa ser imediatamente após, ao contrário do +)

Título

Primeiro parágrafo após H2. A regra h2 ~ p vai estilizar este.

Segundo parágrafo. Também é estilizado, pois vem depois do H2.

Este está dentro de uma div, não é irmão direto do H2, portanto NÃO é estilizado.

Terceiro parágrafo. Também estilizado, pois é irmão subsequente.

Span após os parágrafos. A regra h2 ~ span também o pega.

Quarto parágrafo, também estilizado.

Subtítulo

Primeiro span após H3 (estilizado por h3 ~ span). Strong aqui não é span, não é afetado. Segundo span (também estilizado).
Diferença: Enquanto + pega apenas o primeiro irmão imediato, o ~ pega todos os irmãos que vêm depois (em qualquer posição).
