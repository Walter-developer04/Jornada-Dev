Acessibilidade Web · WCAG 2.1 · Critério 1.4.12

Text Spacing

Textos devem suportar o aumento de espaçamento sem quebrar o layout, cortar ou sobrepor conteúdo.

01

O que é?

Text Spacing (espaçamento de texto) é um critério de acessibilidade das diretrizes WCAG. Ele garante que pessoas com dislexia, baixa visão ou dificuldade de leitura possam ampliar os espaços entre linhas, letras, palavras e parágrafos — por folhas de estilo próprias ou extensões de navegador — sem perder informação.

02

Os quatro ajustes mínimos

Medida Propriedade CSS Valor mínimo exigido
Altura da linha line-height 1,5 × o tamanho da fonte
Espaço entre parágrafos margin-bottom 2 × o tamanho da fonte
Espaço entre letras letter-spacing 0,12 × o tamanho da fonte
Espaço entre palavras word-spacing 0,16 × o tamanho da fonte
03

Na prática

O texto abaixo recebe exatamente os valores da tabela. Use o botão Text Spacing para ligar e desligar o efeito.

A legibilidade não depende apenas do tamanho da fonte. Para muitos leitores, é o espaço entre as linhas que mantém os olhos na frase certa.

Quando o espaçamento é amplo, cada palavra respira. Se o layout quebra ao ampliá-lo, o conteúdo se torna inacessível — e é isso que o critério 1.4.12 vem impedir.

CSS correspondente

.texto {
  line-height: 1.5;
  letter-spacing: 0.12em;
  word-spacing: 0.16em;
}

.texto + .texto {
  margin-bottom: 2em;
}
