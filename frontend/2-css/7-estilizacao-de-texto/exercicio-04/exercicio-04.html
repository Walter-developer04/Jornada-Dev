PROPRIEDADE DO CSS · TEXTO

text-transform

Um guia direto e didático sobre como controlar maiúsculas e minúsculas no texto da sua página usando apenas CSS.

01

O que é?

Imagine que você escreveu um título no HTML todo em letras minúsculas, mas o design pede tudo em CAIXA ALTA. Em vez de reescrever o texto à mão, você deixa o CSS fazer esse trabalho.

A propriedade text-transform altera a caixa das letras (maiúsculas ↔ minúsculas) no momento em que a página é exibida. O texto original, salvo no arquivo HTML, permanece intacto.

Por que isso é útil:

  • Você escreve o texto uma única vez e muda a exibição quando quiser;
  • O conteúdo original fica limpo, sem edições manuais;
  • Uma única linha de CSS padroniza a aparência de toda a página.
02

Sintaxe

A regra funciona assim:

h1 {
  text-transform: uppercase;
}
  • h1 → seletor Escolhe quais elementos serão afetados pela regra.
  • text-transform → propriedade Define o que será controlado: a caixa das letras.
  • uppercase → valor Define como o texto será transformado na tela.
03

Os quatro valores principais

uppercase

Transforma todas as letras em MAIÚSCULAS.

button {
  text-transform: uppercase;
}

Atenção: capitalize age em todas as palavras — inclusive "é", "do" e "que". Ele não sabe quais palavras deveriam permanecer minúsculas em um título; para isso, o texto precisaria ser escrito já formatado.

Uso comum: nomes próprios, nomes de produtos e listas de categorias.

none

Remove qualquer transformação e exibe o texto exatamente como foi escrito. 

.aviso {
  text-transform: uppercase;
}
.aviso .destaque {
  text-transform: none; /* cancela a herança */
}
NA TELA

todo este parágrafo herda uppercase do elemento pai, mas este trecho aqui tem seu próprio none e volta ao original.

Uso comum: cancelar uma transformação que foi herdada do elemento pai, criando uma "exceção" dentro do texto.

04

Observações importantes

  1. A mudança é apenas visual. O texto salvo no arquivo HTML continua exatamente como você escreveu. A transformação acontece só na renderização da página — o que facilita a manutenção e a busca pelo conteúdo.
  2. Não confunda capitalize com "primeira letra da frase". Ele capitaliza cada palavra individualmente, sem entender gramática.
  3. Existem outros valores, como full-width, mas são casos raros ligados a alfabetos asiáticos. No dia a dia, os quatro valores acima resolvem praticamente todas as situações.
