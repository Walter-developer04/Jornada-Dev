A propriedade CSS direction

A propriedade direction no CSS é responsável por definir a direção em que o texto flui e como os elementos da página são organizados.
Ela é essencial para internacionalização, garantindo que o layout se adapte corretamente ao idioma do usuário.

Ela possui dois valores principais:
- ltr (Left-To-Right): O texto flui da esquerda para a direita (padrão para português e inglês).
- rtl (Right-To-Left): O texto flui da direita para a esquerda (usado em idiomas como árabe e hebraico).

Além de inverter a leitura do texto, a direction também altera o início do fluxo do layout, fazendo com que as margens, flutuações (floats) e posicionamentos laterais comecem no lado correspondente.
