PROPRIEDADE DO CSS · TEXTO

text-decoration

Um guia direto e didático sobre como desenhar linhas decorativas abaixo, acima e através do texto usando apenas CSS.

01

O que é?

A decoração de texto mais famosa da web é o sublinhado: todo link recém-criado já nasce com uma linha embaixo. A propriedade text-decoration é quem controla essas linhas — onde elas aparecem (abaixo, acima ou atravessando o texto), com qual estilo, cor e espessura.

O efeito é puramente visual. A linha é desenhada por cima do texto na hora da exibição — o conteúdo salvo no HTML permanece intacto.

Por que isso é útil:

  • Padronizar a aparência de todos os links do site com uma regra só;
  • Riscar preços antigos ou itens esgotados sem editar o conteúdo;
  • Destacar termos com linhas de estilo e cor próprios, mantendo o HTML limpo.
02

Sintaxe

A regra funciona assim:

.destaque {
  text-decoration: underline wavy #eb1636;
}
  • .destaque → seletor Escolhe quais elementos serão afetados pela regra.
  • text-decoration → propriedade Um atalho (shorthand) que resume várias configurações em uma só.
  • underline wavy #eb1636 → valores Linha, estilo e cor — separados por espaço, na mesma declaração.

Como text-decoration é um atalho, a mesma regra poderia ser escrita por extenso, com as propriedades individuais: 

.destaque {
  text-decoration-line:  underline;  /* onde fica a linha     */
  text-decoration-style: wavy;       /* como ela é desenhada */
  text-decoration-color: #eb1636;    /* qual a cor da linha   */
}

No dia a dia, o atalho é mais prático — mas conhecer as versões longas ajuda a mudar só um detalhe quando precisar, sem afetar os demais.

04

Personalizando a linha

A linha não precisa ser um risco fino na cor do texto. O atalho controla três aspectos dela — e cada um pode ser ajustado separadamente.

ESTILO DA LINHA · text-decoration-style

  • solid

    linha contínua — o padrão

  • wavy

    linha ondulada

  • dotted

    linha pontilhada

  • dashed

    linha tracejada

  • double

    linha dupla

COR DA LINHA · text-decoration-color

Por padrão, a linha usa a mesma cor do texto — mas ela pode ter cor própria, diferente da das letras. 

.destaque {
  text-decoration: underline;
  text-decoration-color: #eb1636;
}
PADRÃO

a linha usa a cor do texto

#eb1636

a linha ganha cor própria

#8b8be2

qualquer cor é válida

ESPESSURA DA LINHA · text-decoration-thickness

Nos navegadores atuais, também é possível controlar a espessura da linha: 

.destaque {
  text-decoration: underline;
  text-decoration-thickness: 3px;
}
ESPESSURA PADRÃO

sublinhado comum

→

TUDO JUNTO NO ATALHO

Os quatro ajustes podem ser escritos em uma única declaração, na ordem: linha, estilo, cor e espessura. 

.destaque {
  text-decoration: underline wavy #eb1636 3px;
}
05

Observações importantes

  1. A linha atravessa os filhos — e eles não conseguem cancelá-la. Diferente de propriedades herdadas comuns, quando o pai tem text-decoration, a linha é desenhada pelo ancestral e cobre todo o conteúdo interno. Escrever text-decoration: none em um elemento filho não remove a linha:
    PROVA NA TELA

    Todo este parágrafo foi decorado pelo próprio elemento, e este trecho tenta cancelar com none — mas a linha continua, porque quem desenha é o ancestral.

  2. Não é a mesma coisa que border-bottom. A decoração acompanha o texto linha por linha: se o parágrafo quebra, cada linha recebe o seu traço. A borda, por sua vez, é desenhada uma única vez, sob a caixa inteira do elemento:
    COM TEXT-DECORATION

    Cada linha do parágrafo recebe a sua própria linha decorativa, acompanhando o texto onde ele quebrar.

    COM BORDER-BOTTOM

    A borda é desenhada uma única vez, na parte de baixo da caixa inteira, e não sob cada linha do texto.

  3. Sublinhado é um forte sinal de "isto é um link". Os usuários aprendem essa convenção desde os primeiros sites. Sublinhar texto comum pode gerar confusão — e, ao remover o sublinhado de links, é preciso oferecer outro diferencial visual claro.
  4. Efeitos visuais não substituem a semântica. Um texto riscado com line-through não comunica "removido" a leitores de tela. Para isso, o HTML oferece <del> (removido) e <ins> (inserido).
