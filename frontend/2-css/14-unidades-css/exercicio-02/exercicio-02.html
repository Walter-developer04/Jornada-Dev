Unidade Relativa à Fonte: em

A unidade em é relativa ao font-size do elemento pai ou do próprio elemento. Quando aninhamos elementos com tamanhos em em, o valor se multiplica progressivamente.

Texto no elemento pai: font-size de 20px.

Texto no filho (1.5em de 20px = 30px).

Texto no neto (1.5em de 30px = 45px).
