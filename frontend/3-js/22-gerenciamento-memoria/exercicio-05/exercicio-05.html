    Prática 2 - Escutas que podem ser removidas

    Só é possível remover uma escuta usando a MESMA função da instalação. Funções anônimas criadas na hora não podem ser removidas depois.

    situação: desligada

    Checklist de prevenção

    1. Remova escutas que não são mais necessárias, guardando a função nomeada.
    2. Prefira escutar no próprio elemento a escutar no window ou document.
    3. Evite variáveis globais: mantenha cada dado no menor escopo possível.
    4. Use WeakMap e WeakSet para metadados que devem morrer com o objeto.
    5. Coloque limite em caches: um Map que só cresce é vazamento adiado.
    6. Solte referências grandes quando terminar, atribuindo null com intenção.
