Exercício 02

Debugging Issues

Depuração de problemas em JavaScript. Abra o DevTools com F12 e deixe a aba Console visível durante os três exemplos.

Exemplo 1 - Lendo um erro e sua pilha de chamadas

A função com erro tenta ler o telefone de uma estudante que não possui essa informação cadastrada. A versão corrigida verifica a informação antes de usar. Observe que a página continua funcionando mesmo depois do erro: ele acontece dentro do ouvinte do clique.

Exemplo 2 - Encontrando um bug de lógica

A função soma o valor de uma compra. O total esperado é R$ 125,90, mas a versão com bug devolve R$ 100,90 sem nenhuma mensagem de erro. O rastreio com console.log dentro do laço mostra o caminho para encontrar a causa.

Exemplo 3 - Inspecionando tipos com a pausa do debugger

Os campos de formulário devolvem texto. A versão com bug soma os valores sem converter; a corrigida usa a função Number antes de somar.
